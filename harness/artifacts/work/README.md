# 모델 간 작업 인계

이 폴더는 Claude와 Codex가 서로 작업을 넘길 때만 사용하는 얇은 상태 계층이다. 각 도구의 Feature Team, Agent, Skill의 상세 산출물을 대체하거나 복제하지 않는다.

## 목차

- [사용 규칙](#사용-규칙)
- [파일 계약](#파일-계약)
- [기존 산출물 참조](#기존-산출물-참조)

## 사용 규칙

1. Claude 또는 Codex에서 평소처럼 작업을 시작한다.
2. 다른 모델 또는 새 세션이 실제로 이어받아야 할 때만 `work/<work-id>/`를 만든다.
3. 전환 직전 `STATUS.md`와 `HANDOFF.md`를 갱신한다.
4. 다음 담당자는 두 파일을 읽고, 참조된 기존 산출물과 코드만 추가로 읽는다.
5. 완료된 work-id는 기록 보관이 필요할 때만 사람 확인 후 `archive/`로 옮긴다.

## 파일 계약

| 파일 | 작성 시점 | 목적 |
| --- | --- | --- |
| `STATUS.md` | 모델 또는 세션 전환 직전 | 현재 담당 도구, 단계, 차단 사유, 다음 행동을 한눈에 표시 |
| `HANDOFF.md` | 모델 또는 세션 전환 직전 | 다음 담당자가 필요한 결정, 변경, 검증, 미해결 사항을 제공 |
| `DECISIONS.md` | 결정이 여러 개이거나 장기 참조가 필요할 때만 | 확정 결정과 근거를 누적 |
| `PLAN.md` | 다음 모델에 복잡한 실행 계획을 넘길 때만 | 단계, 변경 대상, 검증 계획을 제공 |
| `VERIFICATION.md` | 검증 결과가 길거나 반복될 때만 | 실제 실행 명령과 결과를 보존 |

## 기존 산출물 참조

- 기능 개발: `artifacts/feature-team/`의 입력·계획·구현 노트·리뷰 결과를 `HANDOFF.md`에서 경로로 참조한다.
- 같은 내용을 이 폴더에 다시 복사하지 않는다.
