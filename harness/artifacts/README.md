# 작업 산출물

| 경로 | 내용 |
| --- | --- |
| `feature-team/` | Feature Team의 입력·계획·구현 노트·리뷰 산출물. 지도는 `feature-team/README.md` |
| `work/<work-id>/` | 모델·세션 전환 시 STATUS.md·HANDOFF.md. `work/README.md`의 공용 계약 적용 |
| `archive/` | 이전 사이클 기록, Git 제외 |

신규 작업은 해당 도구의 역할·스킬에 명시된 파일명과 경로 계약을 따른다. 기존 작업별 하위 폴더 기록은 이동하거나 삭제하지 않는다. 실제 모델·세션 전환에만 공용 인계 파일을 갱신한다.
