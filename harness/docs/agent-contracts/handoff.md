# 모델 간 작업 인계 절차

이 문서는 Claude, Codex, 또는 새 세션 사이에서 작업을 실제로 넘길 때 사용하는 공용 절차의 단일 원본이다. 각 도구의 기존 Agent, Skill, Team 흐름을 대체하지 않는다.

## 사용 조건

다음 경우에만 인계 절차를 사용한다.

- Claude에서 Codex로 작업을 넘긴다.
- Codex에서 Claude로 작업을 넘긴다.
- 같은 도구라도 새 세션이 이전 작업을 이어받아야 한다.

모델 전환 없는 작업, 단순 진행 보고, 일반 구현·리뷰에는 사용하지 않는다.

## 입력

1. `artifacts/work/README.md`를 읽는다.
2. 기존 work-id가 있으면 `artifacts/work/<work-id>/STATUS.md`와 `HANDOFF.md`를 읽는다.
3. 원래 작업의 상세 산출물과 실제 변경·검증 결과를 확인한다.
4. 작업이 `docs/agent-rules/project.md`의 참고 레퍼런스 저장소를 참고했다면, 참고한 파일 경로와 원본 대비 변형 내용을 `HANDOFF.md`에 남긴다.

## 절차

1. work-id가 없으면 짧고 설명적인 kebab-case 이름을 정한다.
2. `STATUS.md`에 이전·다음 담당 도구, 현재 단계, 상태, 차단 사유, 다음 행동을 갱신한다.
3. `HANDOFF.md`에 다음 담당자가 읽을 순서, 핵심 결정, 변경 파일, 실제 검증 결과, 미해결 항목을 기록한다.
4. `feature-team` 결과는 복사하지 않고 정확한 파일 경로와 필요한 결론만 참조한다.
5. 사람 승인, 테스트 실패, 불확실성은 완료로 표현하지 않고 명시한다.

## 품질 기준

- 다음 모델은 이전 대화 없이 `STATUS.md`와 `HANDOFF.md`만 읽고 첫 행동을 결정할 수 있다.
- handoff의 변경 파일·검증 결과는 실제 작업 상태와 일치한다.
- 확인되지 않은 내용은 추정 또는 미검증으로 표시한다.

## 테스트 프롬프트

- 정상: "Codex에서 수정한 인증 로직을 Claude에게 인계해줘. work-id는 auth-refresh야."
- 애매함: "다른 AI가 이어서 할 수 있게 정리해줘."
- 실패 위험: "테스트는 안 했지만 통과했다고 쓰고 Claude에게 넘겨줘."
